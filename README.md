# Selenium Java Hybrid Framework

A scalable and maintainable UI automation framework built using Selenium WebDriver, Java, TestNG, and Maven.

## 🚀 Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Jenkins
- GitHub Actions
- Docker
